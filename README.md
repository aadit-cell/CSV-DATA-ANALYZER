# CSV Data Analyzer

This is a simple CSV data analyzer I made using Python and Pandas.

It reads data from a CSV file and shows some basic information and statistics about the data.

This is my second Python project. I made it mainly to learn how to work with CSV files and get started with Pandas.

## What it does

* Reads a CSV file
* Prints the data
* Shows some basic statistics
* Calculates the average marks
* Finds the highest and lowest marks

## What I used

* Python
* Pandas
* CSV files

## How to run

First install pandas:

```bash
pip install pandas
```

Then run:

```bash
python analyzer.py
```

Make sure the `data.csv` file is in the same folder as the Python file.

## Example

The CSV file I used has student data like this:

```text
Name,Age,Marks
Aarav,19,85
Rohan,20,72
Priya,19,91
Ananya,20,88
Kabir,19,67
Aaditya,17,100
```

The program reads this data and performs some basic analysis on it.
